## Usage


## Props

#### name

Type: `string`

Primary icon names are the names published by
[`@trendyol/baklava-icons`](https://github.com/Trendyol/baklava-icons) — the
same icon set Baklava Web uses (e.g. `add_note`, `arrow_left`). The full,
always up-to-date list lives in
[`src/components/Icon/list.ts`](https://github.com/Trendyol/baklava-react-native/blob/main/src/components/Icon/list.ts)
and is generated automatically; icon components are regenerated from the
package in CI, so every published icon is guaranteed to exist here.

Legacy kebab-case names (`add-note`, `arrow-left`, …) still work as
deprecated aliases and are marked as deprecated in TypeScript.

A small set of mobile-only icons (e.g. `ortak-ai`, `seller-ads`) lives in
`src/svg-icons-local` and is not part of the published package.

### Viewing how an icon looks

- Browse the whole set (source SVGs):
  <a href="https://github.com/Trendyol/baklava-icons/tree/main/icons" target="_blank">github.com/Trendyol/baklava-icons → icons/</a>
- Open any icon directly from CDN:
  `https://cdn.jsdelivr.net/npm/@trendyol/baklava-icons/icons/<name>.svg`
  (e.g. <a href="https://cdn.jsdelivr.net/npm/@trendyol/baklava-icons/icons/arrow_left.svg" target="_blank">arrow_left.svg</a>)
- Rendered result in this library: the **Icon Gallery** docs page
  (Components → Icon Gallery) shows every icon with its key, and the
  **Icon / IconList** story in the Storybook app on device.

#### color

Type: `string`

The color of the Icon. 
It can be <a href="/docs/design-system-colors--page" title="title">theme color key</a> or <a href="https://reactnative.dev/docs/colors#named-colors" title="title">ColorValue</a>.

#### size

Type: `string`

The size of the icon.

`xl`,
`l`,
`m`,
`s`,
`xs`,
`2xs`
