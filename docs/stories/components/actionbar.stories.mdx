# ActionBar

Action Bars contain actionable components such as button, checkbox etc.

The Action Bar remains sticky at the bottom of the screen (always visible). It may contain Button, Checkbox, Texts etc.

## Provider

Developed using Portal so that it stays sticky at the bottom of the screen, independent of the parent layout.
There is no direct portal solution in React Native as <a href="https://legacy.reactjs.org/docs/portals.html" title="title">React Portal</a>.
We use the https://github.com/gorhom/react-native-portal.

Make sure to add `PortalProvider` and `SafeAreaProvider` in your root view.

```jsx
import * as React from 'react';
import { theme, ThemeProvider, PortalProvider } from '@trendyol/baklava-react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import App from './src/App';

export default function Main() {
  return (
    <ThemeProvider theme={theme}>
      <PortalProvider>
        <SafeAreaProvider>
          <App />
        </SafeAreaProvider>
      </PortalProvider>
    </ThemeProvider>
  );
}
```

## Usage

```jsx
<ActionBar>
  <Button
    variant="primary"
    size="l"
    label="Primary Button"
    filled
    onPress={() => {}}
  />
</ActionBar>
```

```jsx
<ActionBar>
  <Button
    variant="primary"
    size="l"
    label="Primary Button"
    filled
    onPress={() => {}}
  />
  <Button
    variant="primary"
    kind="neutral"
    size="l"
    label="Secondary Button"
    filled
    onPress={() => {}}
  />
</ActionBar>
```

```jsx
<ActionBar>
  <Box flexDirection="row" gap="xs">
    <Box flex={1}>
      <Button
        variant="primary"
        kind="neutral"
        size="l"
        label="Secondary"
        filled
        onPress={() => {}}
      />
    </Box>
    <Box flex={1}>
      <Button
        variant="primary"
        size="l"
        label="Primary"
        filled
        onPress={() => {}}
      />
    </Box>
  </Box>
</ActionBar>
```

## Props

#### children (required)

Type: `React.ReactNode`

Content rendered inside the Action Bar. Commonly used with `Button`, `Checkbox`, `Text` or `Icon`.

#### disableSafeArea

Type: `boolean`

Disables the bottom safe area padding. Default value is `false`.
