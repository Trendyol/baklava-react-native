# Upload

Upload component used to select and upload files.

* Clicking the "Select File" button selects the local file.
* When the file is successfully uploaded, it is displayed with an attachment icon.
* If there are any technical or formatting issues, a warning icon is displayed. A caption explains the issue.
* Uploaded or failed files can be removed by clicking the delete icon.

## Usage

The component is controlled. File picking and upload network logic stay in the parent. Upload only renders the UI, validates format/size against the given rules, and disables the select button when `disabled` is true or `maxFiles` is reached.

```jsx
const [files, setFiles] = useState([]);

<Upload
  label="Select File"
  description="You can upload a maximum of 3 files, the total size of which cannot exceed 20 MB."
  files={files}
  onSelectPress={() => {
    // open file picker in parent, then append to files
  }}
  onRemove={id => {
    setFiles(current => current.filter(file => file.id !== id));
  }}
/>
```

```jsx
<Upload
  label="Select File"
  description="You can upload a maximum of 3 files, the total size of which cannot exceed 20 MB."
  files={[
    { id: '1', name: 'dosya_adı.jpg', status: 'uploaded' },
    {
      id: '2',
      name: 'dosya_adı.jpg',
      status: 'error',
      helperText:
        'Yanlış dosya formatı, dosya formatı PDF, PNG, JPG veya JPEG olmalıdır.',
    },
  ]}
  onSelectPress={() => {}}
  onRemove={() => {}}
/>
```

## Props

#### files

Type: `UploadFile[]`

Controlled list of files to display. Default value is `[]`.

Each file object:

* `id`: `string`
* `name`: `string`
* `size?`: `number` (bytes)
* `status`: `uploaded` | `error`
* `helperText?`: `string`

#### onSelectPress

Type: `() => void`

Callback fired when the select file button is pressed. File picking should be handled by the parent.

#### onRemove

Type: `(id: string) => void`

Callback fired when the delete icon of a file item is pressed.

#### label

Type: `string`

Optional title shown above the select button.

#### description

Type: `string`

Optional helper text shown under the label. Commonly used for upload limits.

#### buttonLabel

Type: `string`

Label of the select button. Default value is `Dosya Seç`.

#### disabled

Type: `boolean`

Disables the select button. Default value is `false`.

The select button is also disabled automatically when `files.length >= maxFiles`.

#### maxFiles

Type: `number`

Maximum number of files allowed. Default value is `3`.

#### maxSize

Type: `number`

Maximum allowed file size in bytes. Default value is `20 MB` (`20 * 1024 * 1024`).

If a file `size` exceeds this limit, Upload resolves the item to `error` status with a size helper message.

#### acceptedFormats

Type: `string[]`

Allowed file extensions. Default value is `['pdf', 'png', 'jpg', 'jpeg']`.

If a file name extension is not in this list, Upload resolves the item to `error` status with a format helper message.

#### testID

Type: `string`

Optional test id prefix. Default value is `upload`.
