## Provider
Developed using Portal for easy use of Component.
There is no direct portal solution in React Native as <a href="https://legacy.reactjs.org/docs/portals.html" title="title">React Portal</a>.
We use the https://github.com/gorhom/react-native-portal.

Make sure to add `PortalProvider` in your root view.

```jsx
import * as React from 'react';
import { theme, ThemeProvider, PortalProvider } from '@trendyol/baklava-react-native';
import App from './src/App';

export default function Main() {
  return (
    <ThemeProvider theme={theme}>
      <PortalProvider>
        <App />
      </PortalProvider>
    </ThemeProvider>
  );
}
```

## Usage

```jsx
<SelectBottomSheet
  visible={isVisible}
  type="checkbox"
  selectButtonLabel="Select"
  closeButtonLabel="Close"
  title="Select Options"
  closeButtonAction={() => setVisible(false)}
  selectButtonAction={() => {
    showAlert(selectedOptions);
    setVisible(false);
  }}
  options={options}
  selectedOption={selectedOptions}
  onSelect={handleMultiSelect}
/>
```

## Props

### options (required)

Type: `Option[]`

### type (required)

Type: `'checkbox' | 'radio'`

### onSelect (required)

Type: `Function`

### selectedOption

Type: `string[]`

### maxVisibleItems

Type: `number`, Default value: `6`

Controls the maximum visible list height (`maxVisibleItems × 50 − 15` px). Increase this value when you need a taller sheet with more options before scrolling.

### applyBottomInset

Type: `boolean`, Default value: `false`

Adds safe area padding at the bottom of the list when the sheet is expanded.

### pb

Type: `string`

## Full Page (Max Height)

- By default the sheet height follows the content (short lists stay compact).
- To approach the maximum supported height (~90% of the screen; see BottomSheet), set a higher `maxVisibleItems` and use `applyBottomInset` when needed.
- There is no dedicated `fullPage` prop yet; consumers tune height via `maxVisibleItems`. A long `options` list scrolls inside the expanded area.
- See the FullPage story in Storybook for a reference implementation.

```jsx
<SelectBottomSheet
  visible={isVisible}
  type="checkbox"
  maxVisibleItems={20}
  applyBottomInset
  selectButtonLabel="Tamam"
  closeButtonLabel="Kapat"
  title="Bottom Sheet Title"
  closeButtonAction={() => setVisible(false)}
  selectButtonAction={() => {
    showAlert(selectedOptions);
    setVisible(false);
  }}
  options={options}
  selectedOption={selectedOptions}
  onSelect={handleMultiSelect}
/>
```
