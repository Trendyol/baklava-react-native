# Accordion

Accordion component displays a collapsible content block. The header row contains an optional leading icon, a title and a chevron that rotates when the content is expanded. The content area can hold any React children such as body text and action buttons.

## Usage

```jsx
<Accordion title="Accordion Title">
  <Text variant="body2">
    Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed tincidunt
    tellus, tellus non facilisis.
  </Text>
  <Box flexDirection="row" gap="m">
    <Button label="Button 1" kind="neutral" size="s" />
    <Button label="Button 2" variant="secondary" kind="neutral" size="s" />
  </Box>
</Accordion>
```

<br />

## Props

#### title

Type: `string`

Accordion title.

#### headerIcon

Type: `IconNameType | boolean`

Leading icon on the header. Defaults to `true` which renders the `info` icon. Set to `false` or `null` to hide it, or pass an icon name to render a custom icon.

#### defaultOpen

Type: `boolean`

Whether the accordion is open initially (uncontrolled).

#### open

Type: `boolean`

Controlled value for the open state.

#### onOpenChange

Type: `(open: boolean) => void`

Callback fired when the accordion open state changes.

#### fullWidth

Type: `boolean`

Removes the side borders and border radius so the accordion spans the full width (borders only on top and bottom).

#### children

Type: `React.ReactNode`

Content rendered below the header when the accordion is open.

#### style

Type: `StyleProp<ViewStyle>`

<br />

## AccordionGroup (List)

Use `AccordionGroup` to stack multiple accordions in a list layout. By default, opening one item closes the others (single-select). Set `multiple` to allow multiple open items.

```jsx
<AccordionGroup>
  <Accordion title="Item 1" headerIcon={false}>
    <Text variant="body2">Content 1</Text>
  </Accordion>
  <Accordion title="Item 2" headerIcon="academy">
    <Text variant="body2">Content 2</Text>
  </Accordion>
  <Accordion title="Item 3">
    <Text variant="body2">Content 3</Text>
  </Accordion>
</AccordionGroup>
```

### AccordionGroup Props

#### multiple

Type: `boolean`

When `true`, multiple items can be open at the same time. Defaults to `false` (single-select).

#### defaultOpenIndex

Type: `number`

Index of the initially open accordion item (uncontrolled).
